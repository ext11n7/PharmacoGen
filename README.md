# PharmacoGen

## Текущая версия интерфейса

Исследование дополнительно получает аннотации и типы публикаций из Europe PMC, метаданные рекомендаций CPIC и аннотации ClinPGx по паре препарат–ген. Совпадение пары не означает совпадения конкретного варианта. При недоступности одного источника остальные результаты сохраняются.

Для обзора Gemini задайте серверную переменную `GEMINI_API_KEY` в Netlify; по умолчанию используется `gemini-2.5-flash`, при необходимости имя модели можно изменить через `PHARMACOGEN_LLM_MODEL`. Альтернативно поддерживаются `OPENAI_API_KEY` и `PHARMACOGEN_LLM_MODEL`. После изменения переменных пересоберите приложение; ключ нельзя добавлять в репозиторий или код страницы. Модели передаются запрос и ограниченный набор опубликованных аннотаций и метаданных. Ответ показывается только при наличии ссылок на переданные идентификаторы, но корректность интерпретации всё равно требуется проверить вручную. При отсутствии настройки источники остаются доступны. Перед включением на публичном сайте необходимо настроить защиту от неограниченных запросов и лимит расходов провайдера.

Бесплатный локальный вариант: установите Ollama, запустите `ollama serve` и загрузите модель командой `ollama pull qwen2.5:7b`. Локальный Python-сервер автоматически обнаружит эту модель, если платный провайдер не настроен. Для обзора модель получает только найденные аннотации статей; документы CPIC и записи ClinPGx показаны отдельно. Проверка ссылок не гарантирует достоверность выводов модели: необходимо сверять их с оригиналами. Обработка выполняется на компьютере и может занять несколько минут. При необходимости задайте `PHARMACOGEN_LLM_PROVIDER=ollama` и `PHARMACOGEN_LLM_MODEL` для другого локального варианта. Локальная модель не доступна опубликованному сайту Netlify без отдельного подключённого сервера.

Основной интерфейс запускается командой `.venv/bin/python web_server.py` после установки зависимостей. Откройте `http://127.0.0.1:8503`. Поиск препаратов использует RxNorm, подсказки генов — NCBI Clinical Tables. Доступен и ручной ввод. Отчёт содержит результаты источников, поисковые запросы и ссылки; гипотеза представлена как исследовательский вопрос, требующий проверки.

Локальный веб-сервер вызывает инструменты FAERS и ClinVar через MCP stdio. На странице MCP можно проверить локальный процесс, локальный Streamable HTTP и установленный через npm `medical-mcp`. Журнал вызова представляет реконструкцию запросов и ответов SDK, а не захват сырых пакетов. При недоступности внешних источников в досье сохраняются ответы остальных.

На Netlify статический интерфейс использует отдельные серверные функции для FAERS, ClinVar и PubMed. MCP-транспорты на Netlify не запущены: для их демонстрации используйте локальный Python-сервер. Это ограничение явно показано в интерфейсе. Результаты PubMed — поисковые совпадения, их количество не является мерой доказательности.

Учебный прототип мультиагентного сбора информации из двух источников из согласуемого перечня: **FAERS** и **ClinVar**.

## Идея проекта

Пользователь вводит препарат и ген. Система запускает четыре роли:

1. `Entity Agent` нормализует названия и алиасы.
2. `FAERS Agent` получает число сообщений о нежелательных явлениях и частые реакции из openFDA FAERS.
3. `ClinVar Agent` ищет варианты по паре `ген + препарат` и клинические классификации через NCBI E-utilities.
4. `Synthesis Agent` объединяет результаты, формирует исследовательскую гипотезу и явно перечисляет ограничения.

Важно: приложение не доказывает причинность, не рассчитывает риск для пациента и не является медицинской рекомендацией.

## Запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/streamlit run app.py
```

Откройте адрес, который напечатает Streamlit, обычно `http://localhost:8501`.

## Публикация в web

Репозиторий можно подключить к [Streamlit Community Cloud](https://share.streamlit.io/): укажите главный файл `app.py`. Файл `requirements.txt` уже содержит зависимости, отдельные ключи API не нужны. Для локальной публикации за прокси используйте `streamlit run app.py --server.address 0.0.0.0`.

## Проверка

```bash
.venv/bin/pytest -q
```

## Практическое задание 2: MCP

Проект поддерживает три паттерна MCP:

1. `stdio`: локальный Python-сервер с синтезом доказательств, приоритизацией варианта и контролем качества текущего отчёта.
2. `Streamable HTTP`: локальный MCP-сервер на `http://127.0.0.1:8000/mcp` с теми же аналитическими инструментами.
3. Внешний `medical-mcp`: сервер из каталога [Glama](https://glama.ai/mcp/servers/JamesANZ/medical-mcp), который предоставляет инструменты FDA, PubMed и RxNorm.

Запуск веб-приложения и MCP-клиентов:

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python web_server.py
```

Откройте `http://127.0.0.1:8503` и перейдите к разделу «MCP-лаборатория». После основного исследования нажмите «Анализировать текущий отчёт»: приложение передаст в MCP сводки FAERS и ClinVar. Вызов проходит через последовательность `initialize`, `tools/list`, `tools/call`, а технические пакеты доступны в инспекторе JSON-RPC.

Для внешнего режима приложение запускает пакет `medical-mcp` из Glama через `npx` как stdio MCP-клиент. Первый запуск может занять время на загрузку npm-пакета; после этого приложение применяет ограничение запроса 15 секунд, две попытки и кэш на 5 минут. Если внешний сервер уже запущен по Streamable HTTP, задайте `PHARMACOGEN_EXTERNAL_MCP_URL`, например `http://127.0.0.1:3000/mcp`. Для любого другого запуска stdio задайте `PHARMACOGEN_EXTERNAL_MCP_COMMAND`, например `node /путь/к/medical-mcp/build/index.js`.

Пакет выбран из карточки [medical-mcp в Glama](https://glama.ai/mcp/servers/JamesANZ/medical-mcp). Каталог Glama является источником внешнего MCP-сервера, а не гарантированным публичным URL: приложение запускает опубликованный npm-пакет локально или подключается к URL, который указал пользователь.

Для Netlify подходит статическая веб-часть и существующие serverless-функции проекта. Долгоживущие stdio- и Streamable HTTP-процессы MCP нельзя надёжно держать внутри статического Netlify-хостинга, поэтому полноценную демонстрацию MCP следует запускать локально или на отдельном Python/Node-сервере, а в Netlify передавать внешний URL через `PHARMACOGEN_EXTERNAL_MCP_URL`.

## Сценарий демонстрации

Введите `warfarin` и `CYP2C9`, нажмите «Запустить агентов», затем покажите вкладки «Доказательства» и «Ход агентов». В конце отдельно проговорите, что FAERS содержит спонтанные сообщения, а ClinVar описывает варианты и их интерпретации; их объединение создаёт только гипотезу для последующей проверки.

## Веб-версия

Основной пользовательский интерфейс теперь доступен как самостоятельное веб-приложение без зависимости от Streamlit:

```bash
.venv/bin/python web_server.py
```

Откройте `http://127.0.0.1:8503`. Страница использует текущую мультиагентную логику из `agents.py`, а запросы к FAERS и ClinVar выполняются через локальный API.
