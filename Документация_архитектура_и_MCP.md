# PharmacoGen: архитектура, MCP и модель

## Что требует практическое задание

Практическое задание 2 требует показать три независимых способа подключения MCP-инструментов в одном веб-приложении:

1. **Stdio** — собственный Python MCP-сервер запускается как дочерний процесс, а JSON-RPC проходит через stdin/stdout.
2. **Локальный сетевой MCP** — отдельный сервер слушает порт 8000 и принимает SSE и Streamable HTTP. В проекте оба маршрута доступны: `/sse` и `/mcp`.
3. **Внешний медицинский MCP** — удалённый сервер или пакет из каталога Glama. В проекте поддержаны пакет `medical-mcp` и внешний URL через `PHARMACOGEN_GLAMA_MCP_URL` или `PHARMACOGEN_EXTERNAL_MCP_URL`.

Задание также требует строгие схемы параметров, обработку ошибок, каталог инструментов, динамические формы, визуализацию результата и инспектор JSON-RPC. Важный критерий — вызов должен проходить через MCP-клиента, а не через прямой вызов функции.

## Как устроен проект

Пользователь работает с веб-интерфейсом PharmacoGen. В исследовании он выбирает препарат, ген и вариант. Сервер получает данные FAERS и ClinVar, а MCP-досье дополнительно получает PubMed, CPIC и ClinPGx.

После сбора досье MCP-инструменты могут выполнять отдельные операции: проверять полноту, разбирать записи, искать фразу, сопоставлять вариант, сравнивать записи и строить план дальнейшей проверки. MCP не заменяет исследовательскую логику и не является медицинским выводом.

Схема взаимодействия:

```text
Веб-интерфейс
    ↓
MCP-роутер: выбирает stdio / локальный HTTP / внешний сервер
    ↓
MCP Client: initialize → tools/list → tools/call → shutdown
    ↓
MCP Server: валидирует параметры и запускает Tool
    ↓
JSON-RPC result: content + structuredContent
    ↓
Карточка результата + JSON-RPC инспектор
```

## Собственный stdio-сервер

Файл `mcp_servers/stdio_server.py` — собственный сервер проекта. Он запускается командой:

```bash
python -m mcp_servers.server
```

Сервер использует официальный Python MCP SDK. Логи идут в stderr, поэтому stdout остаётся чистым JSON-RPC-каналом.

В stdio-режиме зарегистрированы исследовательские инструменты PharmacoGen и учебные клинические калькуляторы:

- ИМТ по массе и росту;
- клиренс креатинина Cockcroft–Gault;
- шкала комы Глазго.

Есть мета-инструмент `list_calculators`: он возвращает описание методики, схему параметров, единицы измерения, ограничения и ссылку на источник. Все параметры имеют строгие типы и границы через Pydantic-аннотации. Неправильное значение возвращается как понятная ошибка инструмента.

## Локальный сетевой сервер

Файл `mcp_servers/network_server.py` запускает сервер на `127.0.0.1:8000`. Он предоставляет оба интерфейса SDK:

- `http://127.0.0.1:8000/sse` — SSE для требования задания;
- `http://127.0.0.1:8000/mcp` — современный Streamable HTTP.

Сетевой сервер содержит пять калькуляторов из разных областей: ИМТ, GCS, клиренс креатинина, площадь поверхности тела Mosteller и шоковый индекс. Для каждого инструмента описаны единицы, формула, ограничения и первоисточник.

Клиент автоматически приводит числовые значения из формы к числам, сообщает об изменениях и проверяет границы. Отсутствующие медицинские значения он не выдумывает. При временной ошибке выполняются повторные попытки, а внешний режим ограничен тайм-аутом 15 секунд.

## Внешний MCP из Glama

Внешний пакет `medical-mcp` взят из карточки Glama: он предоставляет поиск лекарств, PubMed, FDA, RxNorm и клинических руководств. Вызов выполняется через отдельный MCP-клиент, а не импортом функций медицинского пакета.

Для удалённого Streamable HTTP можно задать:

```bash
export PHARMACOGEN_GLAMA_MCP_URL="https://адрес-внешнего-mcp/mcp"
```

Если URL не задан, локальный режим запускает установленный npm-пакет `medical-mcp` через stdio. Ответы внешнего сервера ограничены по времени, повторяются при краткой сетевой ошибке и кэшируются на пять минут.

## Веб-интерфейс

Интерфейс написан на HTML, CSS и JavaScript и размещён в `web/`. Он содержит:

- селектор источника MCP;
- каталог и поиск инструментов;
- динамические поля по JSON-схеме инструмента;
- карточку результата с формулой, единицами, интерпретацией и ссылкой;
- индикатор загрузки и понятные ошибки;
- раскрывающийся JSON-RPC-инспектор.

В инспекторе показываются сообщения `initialize`, `notifications/initialized`, `tools/list`, `tools/call` и ответ с `result.content`. Это позволяет увидеть протокол, а не только конечный текст.

## Модель Groq

Для текстовых обзоров подключён API Groq. Используется модель `qwen/qwen3.8-27b`. Ключ хранится в переменной окружения `GROQ_API_KEY` на сервере Netlify и не попадает в браузерный код.

Модель получает ограниченный набор аннотаций и выбранные записи. Она может:

- составить обзор найденной литературы;
- сравнить две выбранные записи;
- выделить общее и различия;
- сформулировать ограничения и следующие шаги.

В режиме сравнения модель получает только два выбранных идентификатора. Ответ обязан содержать ссылки на эти записи. Ссылки проверяются программой; медицинская интерпретация всё равно требует проверки по первоисточникам.

Локально поддерживается Ollama с Qwen 2.5 7B. Публичная версия использует Groq.

## Технологический стек

- HTML, CSS, JavaScript — пользовательский интерфейс;
- Python 3.12/3.15 и Pydantic — локальная серверная часть и схемы;
- официальный Python MCP SDK — stdio и локальный сервер;
- официальный JavaScript MCP SDK — серверная функция Netlify;
- Starlette/Uvicorn и FastMCP SDK — SSE/Streamable HTTP;
- Node.js и npm — внешний `medical-mcp`;
- Netlify Functions — публичные серверные маршруты;
- Groq API + Qwen — текстовые обзоры;
- GitHub — исходный код;
- pytest и Node test runner — проверки.

## Как демонстрировать

1. Открыть приложение и выбрать `warfarin + CYP2C9`.
2. В локальном запуске открыть MCP и выбрать stdio. Показать `calculate_bmi` и `list_calculators`.
3. Выбрать сетевой MCP и показать GCS или клиренс креатинина. Передать строковые числа и показать санитаризацию.
4. Выбрать внешний medical-mcp и вызвать поиск публикаций или FDA-сведения.
5. Раскрыть инспектор и показать `initialize`, `tools/list`, `tools/call` и `result`.
6. На странице исследования выбрать две записи, запустить сравнение и показать сводку Qwen через Groq.

## Ограничения

Калькуляторы являются учебными и не назначают лечение. FAERS — спонтанные сообщения; их число не является частотой и не доказывает причинность. ClinVar описывает вариант в контексте конкретных признаков. Публикация не равна доказательству гипотезы. Внешний MCP зависит от доступности удалённого сервера и сетевых лимитов.
